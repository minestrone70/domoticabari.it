Previsioni meteo e gestione dell’acqua · 03 / 08

Irrigazione

Irrigazione smart: durata variabile in base al meteo passato e previsto.

Come funziona

L’integrazione Met.no fornisce l’entità meteo; l’azione weather.get_forecasts restituisce le previsioni orarie. La probabilità di pioggia nelle prossime tre ore determina un fattore comune per tre elettrovalvole. Soglie e tempi sono esempi da calibrare sul terreno; se la previsione manca, il ciclo viene sospeso.

Esempio Home Assistant

Esempio Home Assistant: adattare entità, credenziali e soglie all’impianto.

automation:
  - alias: "Irrigazione - tre zone secondo previsione"
    triggers:
      - trigger: time
        at: "06:00:00"
    actions:
      - action: weather.get_forecasts
        target:
          entity_id: weather.casa
        data:
          type: hourly
        response_variable: meteo
      - variables:
          probabilita: "{{ meteo['weather.casa'].forecast[:3] | map(attribute='precipitation_probability') | select('number') | list | max(default=none) }}"
      - variables:
          fattore: "{{ 0 if probabilita is none or probabilita >= 70 else 0.4 if probabilita >= 35 else 1 }}"
      - condition: template
        value_template: "{{ fattore | float > 0 }}"
      - repeat:
          for_each:
            - { valvola: switch.elettrovalvola_prato, minuti: 8 }
            - { valvola: switch.elettrovalvola_aiuole, minuti: 5 }
            - { valvola: switch.elettrovalvola_piante, minuti: 4 }
          sequence:
            - action: switch.turn_on
              target:
                entity_id: "{{ repeat.item.valvola }}"
            - delay:
                seconds: "{{ (repeat.item.minuti * 60 * (fattore | float)) | int }}"
            - action: switch.turn_off
              target:
                entity_id: "{{ repeat.item.valvola }}"
